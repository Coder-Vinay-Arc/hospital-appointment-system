# 🏥 Hospital Appointment Management System

A full-stack Hospital Appointment Management System built using **React, Spring Boot, and PostgreSQL**. The application allows users to manage doctors, patients, and appointments through an intuitive dashboard with complete CRUD functionality.

## 🚀 Live Demo

- **Frontend:** https://hospital-appointment-system-beryl.vercel.app
- **Backend:**  https://hospital-appointment-system-1-oxge.onrender.com

---

## ✨ Features

### 📊 Dashboard
- Overview cards
- Appointment statistics
- Recent appointments
- Responsive dashboard layout

### 👨‍⚕️ Doctor Management
- Add Doctor
- Update Doctor
- Delete Doctor
- View Doctor List

### 🧑 Patient Management
- Add Patient
- Update Patient
- Delete Patient
- View Patient List

### 📅 Appointment Management
- Book Appointment
- Update Appointment
- Delete Appointment
- Select doctor & patient
- Time slot selection
- Status management (Pending, Confirmed, Cancelled)

### Frontend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Coder-Vinay-Arc/hospital-appointment-system.git
```

---

### Backend

```bash
cd backend
mvn spring-boot:run
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```
